# Memory Globe — Android test

Installable photo globe: https://moujian421.github.io/memory-globe-test/

Open in Android Chrome, then choose Install app / Add to home screen from its menu.
This repository contains compiled website resources and dependency notices only.
Your photos and GPS remain in your device's browser storage. Satellite imagery and street view require Internet access.
Source code is maintained separately. This site is a testing release, not an APK.
